The MIT-licensed orbScene.ts and handTracker.ts are imported from upstream. Local changes replace amber colors/textures with lavender, reduce exposure/bloom and cap pixel ratio. The Home adapter uses the original scene implementation with a permanently locked camera. Three.js and upstream license notices are preserved. The imported handTracker source is retained for provenance but is no longer bundled or activated.

Rebuild using Node: install dependencies from build-package.json/build-package-lock.json in a temporary directory, then run esbuild orbScene.ts --bundle --format=esm --minify --outfile=orb.js with that node_modules directory on NODE_PATH.

Browser-only integration. The exact user-approved position, target, up vector and zoom are in approvedCamera.ts. Orientation is derived from position/target/up. There are no manual camera controls, gesture inputs or saved-view overrides. Refresh and fresh browser profiles use this same configuration; resizing updates only the aspect ratio. Native Windows rendering is not covered by this browser implementation. No voice/Gateway/provider integration was added.

Activity presentation: OrbSceneApi.setActivity accepts idle/speaking/thinking/processing. Genuine speech or playback selects speaking; a genuine request lifecycle may select thinking/processing until completion, cancellation or failure. The browser has no such connection and explicitly stays idle. Only the central coreSphere and glowSphere scale/opacity use the smoothed speech intensity. The surrounding wireframe keeps its original ambient opacity, and global bloom uses the exact pre-state formula (0.8 + sin(t*0.8)*0.15) in all states. Original ambient shell rotation, orbital/particle paths and density remain active independently of state; the approved camera remains fixed. Active core energy loops every 2.4 seconds with a sustained floor, fades back on idle, and no longer has the old periodic near-blackout. Invalid runtime state values fall back to idle. Real voice integration is not claimed; verification uses test-only state injection.
